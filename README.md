# DEN TIMES Online Store — Static Website Package

This package includes a full static website concept for a premium perfume e-commerce store.

## Included Pages
- `index.html` — Homepage
- `shop.html` — Product listing with filters
- `brands.html` — Brand page
- `offers.html` — Gift sets / offers page
- `about.html` — About page
- `contact.html` — Contact and WhatsApp ordering page
- `product.html` — Product detail template
